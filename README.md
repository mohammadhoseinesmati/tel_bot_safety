# ربات محافظ گروه تلگرام

یک ربات کامل و ماژولار برای محافظت از گروه‌های تلگرام، نوشته‌شده با [aiogram 3](https://docs.aiogram.dev/) (async) و SQLAlchemy.

## امکانات

### محافظت گروه
- **ضد فلاد**: محدودسازی خودکار کاربرانی که پیام زیاد در بازه زمانی کوتاه ارسال می‌کنند.
- **فیلتر کلمات نامناسب**: حذف خودکار پیام‌های حاوی کلمات ممنوعه و اخطار به کاربر.
- **کپچای اعضای جدید**: هنگام ورود عضو جدید، تا زمان حل یک معمای ساده در گروه سایلنت می‌ماند و در صورت عدم پاسخ در مهلت تعیین‌شده، از گروه حذف می‌شود.
- **قفل محتوا**: امکان قفل کردن لینک، یوزرنیم، فوروارد، عکس، ویدیو و استیکر برای اعضای عادی.
- **سیستم اخطار**: اخطار دستی یا خودکار با آستانه قابل تنظیم و اقدام خودکار (سایلنت/اخراج/بن) پس از رسیدن به سقف.
- **مدیریت کامل اعضا**: `/ban` `/unban` `/kick` `/mute` `/unmute` `/warn` `/unwarn` `/promote` `/demote` `/pin` `/unpin`
- **پیام خوش‌آمدگویی و قوانین گروه قابل تنظیم**.
- **پنل تنظیمات گروه** با دکمه‌های شیشه‌ای (`/settings`) برای روشن/خاموش کردن هر محافظت بدون نیاز به حفظ دستورات.

### کنترل مالک ربات (سطح ادمین کل)
دستور `/panel` یک **پنل مدیریت با دکمه شیشه‌ای** باز می‌کند که شامل همه موارد زیر است (دستورات متنی معادل هم برای هرکدام وجود دارد):

- **مدیریت گروه‌های ربات**: لیست تمام گروه‌هایی که ربات هم‌اکنون در آن‌ها فعال است، با یک دکمه برای خارج کردن ربات از هر گروه دلخواه. (`/groups`)
- **کاربران مسدودشده**: به‌طور پیش‌فرض **هر کسی می‌تواند ربات را به گروه خودش اضافه کند**. اگر بخواهید کاربر خاصی نتواند این کار را انجام دهد، او را مسدود کنید؛ در این صورت اگر همان کاربر بخواهد ربات را به گروهی اضافه کند، ربات خودکار از آن گروه خارج می‌شود.
  - `/block USER_ID` – مسدود کردن یک کاربر از افزودن ربات
  - `/unblock USER_ID` – رفع مسدودیت
  - `/blocked` – نمایش لیست کاربران مسدودشده
- **تبلیغات/پیام همگانی**: ارسال یک پیام (متن، عکس، ویدیو و ...) به تمام گروه‌هایی که ربات در آن‌ها فعال است.
  - `/broadcast متن` یا ریپلای روی یک پیام و ارسال `/broadcast`
- **عضویت اجباری کانال**: تعیین یک یا چند کانال که کاربران باید قبل از استفاده از ربات (در چت خصوصی) در آن‌ها عضو شوند.
  - `/addchannel @channel`
  - `/delchannel @channel`
  - `/channels`
- `/stats` – آمار کلی ربات (تعداد گروه‌های فعال و کاربران مسدودشده)

### منوی شروع (چت خصوصی)
با ارسال `/start`، کاربر منویی شیشه‌ای می‌بیند شامل:
- ➕ افزودن ربات به گروه (لینک مستقیم افزودن)
- 📞 پشتیبانی (ارسال پیام مستقیم به مالک ربات و امکان پاسخ با ریپلای)
- 📜 راهنما

## نصب و راه‌اندازی

### ۱. نیازمندی‌ها
- Python 3.11+

### ۲. نصب پکیج‌ها
```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

### ۳. تنظیم متغیرهای محیطی
فایل `.env.example` را کپی کرده و مقداردهی کنید:
```bash
cp .env.example .env
```

| متغیر | توضیح |
|---|---|
| `BOT_TOKEN` | توکن ربات از @BotFather |
| `OWNER_IDS` | شناسه عددی مالک/مالکین ربات (با کاما جدا شود) |
| `SUPPORT_CHAT_ID` | (اختیاری) شناسه چت دریافت پیام‌های پشتیبانی؛ در صورت خالی بودن به همه مالکین ارسال می‌شود |
| `DATABASE_URL` | آدرس دیتابیس (پیش‌فرض SQLite) |

### ۴. اجرا
```bash
python -m bot.main
```

جدول‌های دیتابیس به‌صورت خودکار در اولین اجرا ساخته می‌شوند.

## نکات مهم استقرار
- ربات باید در هر گروه، **ادمین با دسترسی حذف پیام، محدودسازی اعضا و پین پیام** باشد تا محافظت‌ها به‌درستی کار کنند.
- به‌طور پیش‌فرض هر کاربری می‌تواند ربات را به گروه خودش اضافه کند. برای جلوگیری از این کار برای کاربری خاص، از `/panel` ← «کاربران مسدود شده» یا دستور `/block USER_ID` استفاده کنید.
- برای خارج کردن ربات از یک گروه (مثلاً یک گروه نامناسب)، از `/panel` ← «گروه‌های ربات» استفاده کنید و روی گروه مورد نظر بزنید.
